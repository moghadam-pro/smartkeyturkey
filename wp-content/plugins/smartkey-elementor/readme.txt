=== SmartKey Elementor ===
Requires at least: 6.5
Requires PHP: 8.1
Stable tag: 0.2.0

Editable Elementor Theme Builder templates and focused dynamic integrations for SmartKeyTurkey.

== Changelog ==

= 0.2.0 =

* Added Elementor/Elementor Pro document metadata.
* Added a reversible admin switch between Elementor chrome and the PHP fallback.

= 0.1.3 =

* Removed automatic Elementor Pro condition activation; templates are now created safely and must be published through Theme Builder.

= 0.1.2 =

* Saved global conditions through Elementor Pro's Theme Builder conditions manager.

= 0.1.1 =

* Registered global display conditions in Elementor Pro's Theme Builder condition registry.

= 0.1.0 =

* Added native Elementor Header and Footer templates with global display conditions.
* Connected templates to native WordPress menus and editable Elementor widgets.
